# fast-raider-android-
FAST RAIDER 🚖

FAST RAIDER – Your Ride, Your Way.

FAST RAIDER is an Android transportation application designed to connect passengers with drivers quickly and easily.

Features

- 📍 Live location tracking
- 🚕 Request a ride
- 💰 Automatic distance-based pricing
- 🗺️ Google Maps integration
- 👨‍✈️ Driver and passenger accounts
- 📱 Simple, modern interface
- 📋 Ride history
- 🔔 Ride notifications

Platform

Android

Project Status

Under development.

Vision

Making transportation easier, faster, and more accessible.
